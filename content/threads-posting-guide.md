# スレッズ予約投稿の手順

## 結論：スレッズの公式機能で予約できる（外部ツール不要）

2026年9月時点で、Threadsの予約投稿は**公式機能として無料**で使える。
最大**75日先**まで指定できるので、この20本（20日分）は一度に全部仕込める。

### 手順

1. 投稿作成画面を開く
2. 右上の「**…**」メニューをタップ
3. 「**日時を指定…**」を選ぶ
4. 公開したい日時を設定して予約

予約済みの投稿は**下書きフォルダ**から確認・編集・削除ができる。

### 注意

- **ツリー（連投）の予約はできない。** 1投稿ずつ別の日に分ける前提で原稿を作ってある
  （セット1の②は「昨日の投稿」と書いてあるので、①→②は必ず連続した日に）
- 予約の取り消し・時刻変更は下書きフォルダから
- 本文を貼ったあと、**②の投稿は `{{ここにアフィリリンク}}` を実際のリンクに差し替える**

### 21:30にした理由

ターゲットが35〜45歳の働く女性で、仕事・子育て・家事が一段落する時間帯。
テーマが「眠る・いたわる」中心なので、**寝る前の時間に届くほうが刺さりやすい**。

ただしこれは仮説。最初の1週間が終わったら、
朝（6:30〜7:30／通勤前）と夜（21:30）で伸びを比べて寄せていくのがいい。

毎日がきつければ、**火・木・土の週3本**に薄めてもいい。
その場合は①と②が離れすぎないように、同じ週の中でペアを完結させる。

## 外部ツールを使う場合

公式機能で足りるので基本は不要。ただし
**複数SNS同時投稿・チーム運用・分析をまとめたい**なら外部ツールに意味がある。

- `content/threads-schedule.csv` をそのまま読み込める一括入稿に対応したツールが多い
- 使うツールが決まったら、そのツールのCSVフォーマットに合わせて作り直せる

### APIで自動化したい場合（参考）

Threads APIには**予約投稿の機能がない**。
`scheduled_publish_time` のようなパラメータは存在せず、APIは呼んだ瞬間に公開する。
予約したいなら、自分側で待ってから叩く仕組みを作る必要がある。

- 1プロフィールあたり **24時間で250投稿**まで（API経由）
- API経由ではツリー（連投リプライ）を作れない
- 公開後の本文編集もAPIではできない

20本/20日の運用規模なら、**公式の予約機能のほうが確実に早い**。
